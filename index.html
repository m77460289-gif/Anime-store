درباره نیگا

فروشگاه محصولات و اکسسوری‌های دنیای انیمه

در نسخهٔ پشتیبان سایت، نام فروشگاه «anime-shop» و محصولاتی با عنوان نیگا ثبت شده‌اند. این پیش‌نمایش بر پایهٔ اطلاعات عمومی و تصاویر رسانه‌ای موجود در همان نسخه ساخته شده است.

این پروژه ظاهر فروشگاه را به HTML، CSS و JavaScript تبدیل می‌کند تا بتوان آن را روی GitHub Pages دید. فایل‌های اصلی WordPress و بک‌اند، برای اجرای فروشگاه واقعی لازم هستند و عمداً از این نسخهٔ عمومی کنار گذاشته شده‌اند.
