# فروشگاه نیگا (NIGA Store)

پروژهٔ کلاسی فروشگاه انیمه با HTML، CSS و JavaScript؛ قابل مشاهده و استفاده مستقیم روی GitHub Pages.

## مشاهده سایت
https://m77460289-gif.github.io/Anime-store/

## امکانات نسخهٔ نمایشی
- نمایش، جست‌وجو، دسته‌بندی و مرتب‌سازی محصولات
- سبد خرید با ذخیره در مرورگر
- ثبت‌نام و ورود نمایشی
- ثبت سفارش آزمایشی و مشاهده وضعیت سفارش
- پنل مدیر برای افزودن، ویرایش و حذف محصولات و تغییر وضعیت سفارش
- فرم تماس نمایشی

## حساب مدیر نمایشی
- ایمیل: `admin@niga.local`
- رمز عبور: `Admin12345!`

## نکته‌های پروژه
این نسخه یک پروژهٔ کلاسی و کاملاً استاتیک است؛ بک‌اند یا سرور جداگانه لازم ندارد. اطلاعات حساب‌ها، سبد خرید، محصولات و سفارش‌ها فقط در حافظهٔ مرورگر همان دستگاه ذخیره می‌شوند و بین کاربران یا دستگاه‌های مختلف مشترک نیستند. پرداخت بانکی واقعی در نظر گرفته نشده است.
